# Bulk-Rename-Utility
A lightweight, portable, browser‑based bulk file renamer with a clean UI inspired by Bulk Rename Utility — rebuilt in pure HTML, CSS, and JavaScript. Runs entirely client‑side. No installs, no dependencies, no server, no tracking.
